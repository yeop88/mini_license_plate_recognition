# 한국 번호판 학습 데이터 무료로 구하는 방법

정리일 2026-11-20. 지금 쓰는 YOLO 번호판 감지기(`YOLO-v1s`)는 여러 나라 번호판으로 학습된 모델이라 한국 번호판에 약합니다(`README.md` 시험 기록). 한국 번호판 데이터로 추가 학습(파인튜닝)하려고 무료 데이터를 찾은 결과입니다.

> 라이선스·이용 조건은 각 페이지에서 직접 확인해야 합니다. 번호판은 개인정보 성격이 있어, 받은 데이터와 학습 결과를 다시 공개할 때 특히 조심합니다.

## 1. AI Hub — 자동차 차종/연식/번호판 인식용 영상

- 사이트: https://aihub.or.kr 에서 "자동차 차종/연식/번호판 인식용 영상" 검색
- 내용 (논문에 적힌 값, 받을 때 최신 정보 확인):
  - CCTV 영상에서 차종·연식·번호판을 식별하는 AI 학습용
  - 국산 차량 외관 영상 약 110만 장, JSON 라벨
  - 개인정보 문제로 차량과 번호판을 따로 구축
  - 이 데이터로 번호판 검출 98.9%, 글자 인식 94.2% 를 보고한 연구가 있음
- 받는 방법
  1. aihub.or.kr 회원가입 → 데이터 상세 페이지에서 **이용 조건·약관 확인** → 다운로드 신청 (승인 후 받기). 이용 대상(내국인 한정 여부 등)은 상세 페이지에서 확인
  2. 양이 많으면 AI Hub 의 명령줄 도구 **aihubshell** 로 받기 ([aihubshell 가이드](https://www.aihub.or.kr/static/pdf/aihubshell_가이드.pdf))
  3. JSON 라벨 → YOLO 형식(`class cx cy w h`, 0~1) 으로 바꾸는 스크립트가 필요
- 참고: Roboflow 에 이 데이터를 가공해 올린 [carplate-aihub](https://universe.roboflow.com/segyolov5/carplate-aihub) 도 있음 (제3자 가공본. 원 데이터 이용 조건도 함께 확인)

## 3. GitHub 합성 번호판 생성기

| 저장소 | 내용 |
| --- | --- |
| [kstar1996/Car_Plate_DataGenerator](https://github.com/kstar1996/Car_Plate_DataGenerator) | 한국 번호판 합성 + 합성 번호판을 차량 사진에 붙이는 스크립트. "합성으로 사전학습 → 실제 사진으로 파인튜닝" 권장 |
| [Usmankhujaev/KoreanCarPlateGenerator](https://github.com/Usmankhujaev/KoreanCarPlateGenerator) | 모양·바탕색별 한국 번호판 무작위 생성 |
| [qjadud1994/Korean-license-plate-Generator](https://relatedrepos.com/gh/qjadud1994/Korean-license-plate-Generator) | 한국 번호판 합성 생성기 (마지막 업데이트 약 3년 전) |
| [youngkyung/SynthText_kr](https://github.com/youngkyung/SynthText_kr) | 한글 장면 글자 합성 (글자 인식기 학습 보조) |

- 이 프로젝트의 `plate_types_test.py` 도 종류별(일반·영업용·렌터카·전기차·법인·외교·건설기계·이륜차) 번호판을 그려 차량에 붙이고 거리·각도를 바꿔 투영합니다. 라벨(정답 박스·글자)이 함께 나오므로 합성 학습 데이터 생성기로 키울 수 있습니다.
- 합성만으로 학습하면 실제 사진에서 성능이 떨어지므로, 실제 사진(AI Hub·Roboflow)과 섞어 씁니다.

## 4. 연구용 데이터

- [RLPR (Realistic License Plate Restoration and Recognition)](https://data.mendeley.com/datasets/4rs5wpvckz): 블랙박스 영상의 저화질 번호판 연속 프레임 + 고화질 기준 이미지. 숫자만 라벨이고 한글은 개인정보 때문에 흐리게 처리. 감지 박스가 없어 감지기 학습에는 맞지 않음
- [Sensors 2021, 한국 번호판 실제·합성 데이터 논문](https://minhdl93.github.io/public/papers/sensors_2021.pdf): 대규모 한국 번호판 데이터(실제 + 합성)를 소개. 데이터 공개 여부는 논문·저자에게 확인

## 추천 순서 (이 프로젝트)

1. **Roboflow** 의 CC BY 4.0 한국 번호판 데이터를 YOLOv11 형식으로 받아, 지금 가중치(`models\plate_yolo\license-plate-finetune-v1s.pt` 또는 m/l)에서 파인튜닝 → `models\plate_yolo\` 에 넣으면 앱 목록에 자동으로 추가됨
2. 부족한 종류(영업용 노랑, 이륜차, 연두색, 하늘색)는 합성 생성기로 보충
3. 더 큰 데이터가 필요하면 **AI Hub** 신청 (승인 시간이 걸리므로 미리 신청)
4. 학습 뒤 `plate_robustness_test.py`, `plate_types_test.py` 로 거리·각도·종류별로 다시 시험하고, 실제 카메라로 확인
