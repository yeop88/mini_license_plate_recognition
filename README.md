# mini_license_plate_recognition — 카메라 번호판 인식

USB 카메라 영상에서 **자동차 번호판을 찾고(감지) → 따라가고(추적) → 글자를 읽는(인식)** GUI 프로그램입니다.

- 카메라 쪽은 완성되어 있습니다: 카메라 검색·해상도 선택·스펙 저장, 렌즈 왜곡 분석·보정, 가이드선, 초점 도우미, 캡처
- 인식 쪽은 틀이 완성되어 있습니다: 카메라/영상 입력 → 번호판 감지 → 추적(화면 ID) → 글자 인식 → 여러 번 읽어 다수결로 번호 고정 → 결과 화면·캡처
- **번호판 감지 모델과 글자 인식 모델은 아직 없습니다.** 모델이 생기면 `app\models\plate_models.py` 에 등록하면 인식 설정 창에 나타납니다 (아래 "모델 등록").

## 실행

Anaconda 환경 `physical_ai` (Python 3.11) 를 씁니다.

```bat
run.bat                                    :: 콘솔 창 없이 실행 (지난번 카메라·해상도)
pythonw main.py --camera 1 --size 640x480  :: 카메라 번호·해상도 지정
pythonw main.py --mode max_fps             :: 최고 프레임 (max_quality = 최고 화질, request = 기본 1920x1080)
pythonw main.py --video D:\영상\road.mp4    :: 영상 파일로 시작 (감지기가 있으면 바로 재생)
pythonw main.py --detector P1 --reader R1  :: 등록한 모델 키 (생략하면 첫 번째 등록 모델)
```

## 화면

```
┌ 메인 창 ────────────────────────────────────────────────────┐  ┌ 카메라 설정 (별도 창) ┐
│ [⚙ 카메라 설정] [⚙ 인식 설정] │ [▶ 인식 시작 (I)] [카메라 캡처] [종료]   상태 │  │ 카메라·해상도         │
│                                                              │  │ 렌즈 왜곡 분석·보정    │
│   영상 (카메라 화면 / 인식 결과 화면)                         │  │ 가이드선 / 초점        │
│   (영상 파일일 때만 아래에 재생바)                             │  └────────────────────┘
│                                                              │  ┌ 인식 설정 (별도 창) ──┐
│ 메시지 (카메라·[인식] 메시지)                                  │  │ 입력, 모델, 실행, 옵션  │
└──────────────────────────────────────────────────────────────┘  │ 캡처, 상태, 번호판 목록 │
                                                                   └────────────────────┘
```

- **[⚙ 카메라 설정] / [⚙ 인식 설정]** 을 누르면 메인 창 오른쪽에 **별도 창**이 뜹니다. 다시 누르거나 창의 X 를 누르면 닫힙니다(설정은 유지). 두 창을 함께 열어 두고 눌러 보며 시험할 수 있습니다.
- 시작할 때는 카메라 영상만 띄우고 기능은 모두 꺼져 있습니다. 인식은 **[▶ 인식 시작]** 또는 **I** 키.

| 입력 / 상태 | 영상에 보이는 것 |
| --- | --- |
| 카메라, 인식 꺼짐 | 카메라 영상 (보정 화면이면 왜곡 제거) + 카메라 정보·가이드선·초점 도우미 |
| 카메라, 인식 켜짐 | 인식 결과(번호판 박스·번호·노란 ID) 위에 같은 카메라 정보·가이드선. 인식 정보 줄은 오른쪽 아래 |
| 영상 파일 | 인식 결과, 아래 재생바 (클릭 점프·드래그) |

**보정 화면(U)이 켜져 있으면 인식도 왜곡을 편 영상으로 합니다.**

### 카메라 설정 창

| 묶음 | 내용 |
| --- | --- |
| 카메라 | 카메라 목록, 해상도 목록(기본 / 최고 프레임 / 최고 화질 / 지원 해상도 전체), [새로고침] [스펙 다시 측정] [캡처] |
| 렌즈 왜곡 분석·보정 | [분석 D] [자동 인식 A] [자동 보정 C] [보정 화면 U] [초기화 R] [캡처로 보정 K] [보정값 저장] [체커보드 이미지 저장] |
| 가이드선 | [가이드선 G], 종류 7가지 (V): 전체 / 정사각 격자 / 촘촘한 격자 / 3분할 / 중심·동심원 / 대각선 / 체커보드 |
| 초점 (수동 렌즈) | [초점 도우미 F] [피킹 P] [피킹 감도] [최고값 초기화] + 선명도 요약 |

- 카메라는 **이름**으로 구분해 스펙을 `camera_profiles.json` 에 저장합니다. 처음 보는 카메라는 스펙을 먼저 잽니다(30초~1분).
- 보정값은 카메라별 `calibration_<이름>.json`. 그 카메라를 열면 자동으로 불러옵니다.
- 카메라 캡처(Space)는 `captures\camera\` 에 원본 PNG. **[캡처로 보정]** 은 여기서 현재 해상도와 같은 최근 캡처를 최대 10장 씁니다 (체커보드를 찍은 캡처).

| 묶음 | 내용 |

| 현재 화면 번호판 / 최근 고정 | ID, 번호, 상태(읽는 중 n/N, 고정 %), 신뢰도 / 최근 고정된 번호 50개 |

## 처리 흐름

```
카메라 (CameraStream 스레드, 최신 프레임, 보정 화면이면 왜곡 제거) ─┐
                                                                   ├─ RecognitionPipeline 스레드
영상 파일                                                          ─┘   번호판 감지 → 추적 (IoU + 등속 예측, 화면 ID)
                                                                        → 읽는 중인 번호판만 잘라서 글자 인식
                                                                        → N번 읽으면 다수결로 번호 고정 → 결과 이미지 → (캡처 저장 스레드)
```

- 카메라 입력은 처리가 카메라보다 느리면 중간 프레임을 건너뛰고 항상 **최신 프레임**을 처리합니다.
- 추적(`app\models\tracker.py`, 학습 불필요): 방향 상관없이 중심 이동 속도로 다음 위치를 예상해 IoU 로 짝짓습니다. 화면 가장자리에 걸려 일부만 보이는 번호판은 다 보일 때까지 읽지 않습니다. 큰 박스 안에 80% 이상 들어간 작은 박스는 같은 번호판의 중복으로 봅니다.
- 글자 고정: 못 읽은 프레임(빈 글자)은 세지 않고, 읽은 글자가 N개(기본 5) 모이면 가장 많이 나온 글자로 고정합니다(같으면 신뢰도 합이 큰 쪽). 다 읽기 전에 화면 밖으로 나가면 모은 만큼으로 고정합니다.
- 번호판 글자(한글)는 맑은 고딕으로 그립니다.

## 모델 등록

`app\models\plate_models.py` 의 `DETECTORS`, `READERS` 에 추가합니다. 가중치는 `models\<이름>\` 에 둡니다(저장소에는 올리지 않음).

| 종류 | 만드는 함수 | 돌려주는 함수 |
| --- | --- | --- |
| 감지기 | `build(device)` | `detect(frame_bgr) → (xyxy (N,4), conf (N,))` |
| 글자 인식 | `build(device)` | `read([번호판 이미지, ...]) → [("12가3456", 0.93), ...]` (못 읽으면 `("", 0.0)`) |

```python
def _build_yolo_plate(device):
    from ultralytics import YOLO
    model = YOLO(os.path.join(MODELS_DIR, "plate_det", "best.pt"))
    def detect(frame):
        r = model.predict(frame, conf=0.25, device=device, verbose=False)[0]
        return r.boxes.xyxy.cpu().numpy(), r.boxes.conf.cpu().numpy()
    return detect

DETECTORS["P1"] = {"name": "YOLO 번호판", "build": _build_yolo_plate}
```

| 층 | 하는 일 | 모르는 것 |
| --- | --- | --- |
| Model | 카메라 장치, 스펙·보정, 번호판 모델·추적·저장 | 화면, 버튼 |

## 이 PC 의 카메라

- 0번 "EShare Virtual Camera"(가상), **1번 "Global Shutter Camera"** = ELP-U3GS05B10C-IB8 5MP USB 글로벌 셔터, 수동 초점 렌즈(오토포커스 불가).
- 2026-11-13 측정: 2592x1944 MJPG 38~40 fps, 2048x1536 60 fps, 1920x1080 60 fps, 1280x720 60 fps.
- **2026-11-20 확인**: 1920x1080 MJPG 가 약 1 fps·검은 화면 (프로그램 없이 OpenCV 만으로도 같음), **640x480 은 60 fps 정상** → USB 연결 문제로 보임. 케이블을 본체 뒷면 USB 3 포트에 다시 꽂아 보세요. 그동안은 해상도 목록에서 640x480 을 고르면 됩니다.
